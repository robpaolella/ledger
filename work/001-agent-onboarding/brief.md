# 001 — Agent onboarding

## Ask
Onboard the ledger repo for Pi: add AGENTS.md so agents know the stack, checks, and
project-specific rules before making changes.

## Starting point
No AGENTS.md or CLAUDE.md existed. `.github/copilot-instructions.md` had a large,
actively maintained set of repo-specific rules (design system, permission system, a
dated "Project Learnings" log) written for GitHub Copilot, which Pi never reads.

## Done means
- AGENTS.md exists, following the maestro template, filled from the repo (not invented).
- Checks section is proven to pass on a clean main.
- work/ and backlog.md exist.
- Repo's row in /git/maestro/docs/projects.md is updated (separate PR).
