## How it was done

- Launched with the verify skill on a fresh throwaway database, then driven by script through Chrome (puppeteer-core, one browser profile per role) with real sign-in as owner (John), admin (Jane) and the limited member. Light or dark is set the way the app saves it (`ledger-theme`), then the page is reloaded. No token was injected and no database was edited by hand.
- Sizes: 390×844 and 1440×900 (read back from the page).
- Failed and slow loads were made by blocking or holding the page's own request at the browser (the server was never changed). The two-step sign-in screen was reached by answering the sign-in call locally, as part A did; everything else is the real server.
- Tap sizes were measured by probing the page with `elementFromPoint` around each control, so invisible tap areas count. That is why a control with a 20px text box and a 44px tap area passes.
- Each finding was re-checked in every role, theme and width part A found it in (owner, admin and the member; light and dark; 1440 and 390), except where a role cannot reach the control (the member has no Delete asset, Unsplit or enabled Add account). Every check is a script that asserts the expected state (for example, the exact message or a tap area of at least 44px) and takes a screenshot; none failed.
- Destructive steps stop at their confirmation (delete asset, unsplit). Part A's sample-data change (deleted Honda Civic) does not apply: this is a fresh database.
- **Sample data:** one test balance was saved by accident in a first, abandoned version of the empty-field check (it did not fully clear the field before saving), so Joint Checking shows $7,960.00 instead of $7,960.79 and Accounts' Liquid total $115,970.66 instead of $115,971.45 in every screenshot taken after that point. This is the throwaway sample database only. The final scripts clear the field and refuse to save otherwise.
- Screenshots are in `screenshots/recheck/a/`, named `<issue>-<page>-<role>-<theme>-<width>.png` (`a-327-<sheet>-open|after-escape-…` for #327). Sample data only.
